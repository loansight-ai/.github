# LoanSight AI

**기업 여신심사를 위한 재무·공시 분석 지원 서비스**

KB Bridge 4조참치 · Fin AI Lab
프로젝트명 확정: 2026-10-22 · README 갱신: 2026-10-29

기획안 v2.3 · 요구사항 v0.0.7 · PRD/기능명세서 v0.0.6 · WBS v1.4

은행의 기업금융·여신심사 담당자가 핵심 재무정보와 위험 근거를 한눈에 확인하고, 추가 확인 사항을 정리하도록 돕는 웹 서비스를 개발합니다.

## 해결하려는 문제

재무제표는 항목이 많아 영업이익과 현금흐름 변화를 빠르게 파악하기 어렵습니다. 공시 주석의 소송·보증·담보 정보를 찾아 검토하고, 확인 내용을 기록하는 데에도 시간이 필요합니다. LoanSight AI는 수치·원문 근거·확인 상태를 연결해 검토를 지원합니다.

## 서비스 흐름

**기업 선택 → 공시·재무·주석 수집 → 재무·주석 분석 → 규칙 위험 패널·위험 사건 확률/근거 확인 → 담당자 검토·기록 → 최종 여신 판단**

## 핵심 개발 범위

| 기능 | 내용 |
| --- | --- |
| 핵심 재무 시각화 | 영업이익·현금흐름과 업종별 중요 항목 강조 |
| 실적 변동 분석 | 매출·원가·판관비 변동 기여도와 이익·현금흐름 차이 확인 |
| AI 주석 분석 | 공통·업종 주석 추출·원문 구간/교차참조·검출 상태·근거 요약 |
| 업종별 위험 패널 | 6개 판단 관점·v2.3 징후 기준·경고/주의/관찰, 지표 추세·업종 차트·원문 근거. 기존 주석 화면에 통합 |
| 재무·주석 결합 위험 사건 예측 | 향후 12개월 상환·연체 위험 사건 확률 추정 모델 개발과 제공/보류 상태·원문 근거 연결 |
| 심사 업무 지원 | 확인 체크·미확인 항목 관리·검토 기록 초안 |
| 관련 뉴스 (보완) | 기업·실적 관련성을 재검증한 기사 요약·원문 연결 |

뉴스는 초기 위험 사건 모델 입력에서 제외합니다. 예측과 AI 요약은 검토 보조 정보이며, 내부 자료 확인과 최종 대출 판단은 담당자가 수행합니다.

## 진행 방향

기획·데이터 확보 → 핵심 기능·모델 개발 → 제공 상태·한계 정리 → 시연·발표 순으로 진행합니다. 초기 대상은 공시·재무 확보가 가능한 상장사 중심의 제조·건설·도소매·부동산 임대 4개 업종이며 장비/물품 렌탈은 제외합니다. 업종·비상장·외부 통계·PDF 확대는 후속 범위입니다.

규칙 단계·모델 확률·담당자 체크는 구분합니다. 단계 임계값과 현직자 확인, 서비스 제공 조건은 미정 상태를 유지합니다.

이 페이지는 확정 주제와 개발 계획을 소개합니다. 개별 기능의 구현 완료나 모델 성능·업무 개선 효과는 실제 검증 결과로 확인합니다.
